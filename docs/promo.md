# 홍보 준비물 (2026-08-31 작성, 집행은 승인 + Unsplash Production 이후)

## 0. 집행 전 필수 조건
1. **크롬 웹스토어 게시 완료** — 게시 전 링크를 뿌리면 404 가 된다.
2. **Unsplash Production 승인** — Demo 키는 시간당 50회를 전 사용자가 공유한다. 수십 명이 동시에 들어오면 신규 사용자 첫 화면이 빈다. 이게 안 되면 홍보하지 않는다.
3. **소개 사이트 설치 버튼 활성화** — `index.html` 의 `<body class="pending">` 에서 `class="pending"` 만 지우면 '심사 중' 문구가 '크롬에 추가하기' 버튼으로 바뀐다. 스토어 URL 은 이미 박혀 있다.
4. 캐시 없는 새 크롬 프로필에서 설치 → 첫 새 탭까지 한 번 돌려 본다.

## 1. 네이버 카페 글 (정보형)

### 왜 정보형인가
여행 카페는 홍보성 글을 삭제·강퇴로 처리한다. 규정을 먼저 읽고, **내 글이 링크 없이도 읽을 값이 있는지**로 판단한다. 링크는 본문 맨 끝에 한 번만, 설명과 함께 붙인다. 등업 조건이 있는 카페라면 며칠 활동한 뒤에 올린다.

### 제목안
- 새 탭 열 때마다 여행지 한 곳씩 띄워 두니까 실제로 예약을 하게 되더라고요
- "언젠가 가야지" 하던 도시, 새 탭에 띄워 놓고 3개월 (직접 만든 크롬 확장)
- 여행 가고 싶은 마음이 식지 않게 하는 법 — 새 탭을 여행지로 바꿔 뒀습니다

### 본문 초안
```
여행 계획을 세우다 흐지부지되는 게 반복돼서, 새 탭을 열 때마다 여행지가 한 곳씩
뜨게 만들어 봤습니다. 크롬 확장 프로그램이고 직접 만들었습니다.

계기는 단순합니다. 가고 싶다고 말은 하는데, 검색창을 열 이유가 없으니 그걸로 끝나더군요.
그래서 검색창 자리에 여행지를 놔 봤습니다. 하루에 한 도시씩, 사진 한 장과 문장 하나.

쓰다 보니 알게 된 것들:

1. 사진만으로는 오래 못 갑니다
   처음엔 배경화면만 바꾸는 수준으로 만들었는데 일주일 만에 눈에 안 들어오더군요.
   그래서 도시마다 정보를 붙였습니다. 인천에서 몇 시간인지, 시차가 몇 시간인지,
   언제 가야 좋은지. 이 세 줄이 있으니 "지금 갈 만한가"가 바로 판단됩니다.

2. 비행시간을 알면 후보가 확 줄어듭니다
   2박 3일이면 3시간 안쪽, 4박이면 6시간까지. 이 기준만 있어도 목적지 고르는 시간이
   줄어듭니다. 반대로 장거리는 연차부터 확인하게 되고요.

3. 숙소는 호텔 이름보다 동네를 먼저 정해야 합니다
   같은 예산이라도 어느 동네냐에 따라 매일 이동 시간이 달라집니다.
   도시마다 지역 두세 곳과 특징을 한 줄씩 정리해 뒀습니다.
   (예: 오사카는 난바가 첫 방문 표준, 우메다는 교토 당일치기 편함, 텐노지는 조용하고 저렴)

지금은 인천 직항이 있는 60개 도시가 들어 있습니다.
회원가입은 없고, 저장되는 건 전부 브라우저 안에만 남습니다.

혹시 써 보실 분 있을까 해서 남깁니다. 무료입니다.
→ (설치 페이지 링크)
※ 항공권·숙소 버튼은 제휴 링크라 예약이 이루어지면 제가 수수료를 받습니다.
   이용자가 내는 금액은 달라지지 않습니다. 미리 밝혀 둡니다.
```

### 규칙
- **제휴 링크 사용 사실을 본문에 반드시 밝힌다.** 나중에 걸리면 계정과 신뢰를 같이 잃는다.
- 카페 2곳에 **같은 날 같은 글을 올리지 않는다.** 3~4일 간격, 문장도 바꾼다.
- 댓글 질문에는 기능 자랑이 아니라 사실로 답한다. 모르는 건 모른다고 한다.
- 반응이 나쁘면 글을 지우고 원인을 적어 둔다. 다음 채널에서 같은 실수를 반복하지 않는다.

## 2. 소개 사이트 설치 버튼 (코드 완료)
- `index.html` 상단, 소개 문단 바로 아래에 흰색 알약 버튼 + "무료입니다. 설치 후 새 탭 변경 안내가 뜨면 '유지'를 누르십시오."
- 승인 전에는 `body.pending` CSS 로 '크롬 웹스토어 심사 중입니다' 문구만 노출.
- **승인 당일 할 일: `<body class="pending">` → `<body>` 로 고치고 푸시.** 그것으로 끝난다.
